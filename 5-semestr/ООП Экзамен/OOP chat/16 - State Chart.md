# **16. Диаграмма Statechart (диаграмма состояний)**

## **Назначение**

* Используется для **моделирования состояний объекта** и **переходов между ними**.
* Показывает, **как объект ведёт себя во времени**, реагируя на события и сообщения.
* Отвечает на вопрос:
  **«В каком состоянии находится объект и когда он из него выходит?»**

---

## **Основные элементы**

* **Start State** — начальное состояние (всегда одно).
* **End State** — конечное состояние (может быть несколько).
* **State** — состояние объекта (ожидание, обработка, проверка).
* **State Transition** — переход между состояниями (стрелка).
* **Transition to self** — переход объекта в то же состояние.

---

## **Особенности**

* Основана на принципе **конечных автоматов**.
* Отражает **дискретные состояния**, а не действия.
* Хорошо подходит для **малоактивных объектов**, которые большую часть времени находятся в ожидании.
* **ООП-принципы:**

  * абстрагирование
  * параллелизм
* Не показывает пошаговые действия — только смену состояний.

---

## **Пример (контроллер теплицы)**

1. Start State
2. Ожидание
3. Проверка времени
4. Тестирование окружающей среды
5. Включение исполнительных устройств
6. Возврат в ожидание или End State

➡️ Диаграмма показывает **жизненный цикл объекта «Контроллер»**, а не конкретные шаги работы.
