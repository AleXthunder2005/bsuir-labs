## 29. Функциональные возможности Rational Rose

### 1. Component Assignment Tool (модуль назначения компонентов)

**Назначение:**
Component Assignment Tool предназначен для связывания классов модели Rational Rose с компонентами конкретного языка программирования (например, Visual C++), что необходимо для последующей генерации программного кода.

**Основные функции:**

* Назначение языка программирования для класса (VC++).
* Связывание класса с конкретным программным компонентом.
* Обеспечение доступа к иерархии классов библиотеки MFC при выборе языка VC++.
* Просмотр классов, которые ещё не назначены ни одному компоненту.

**Порядок работы:**

1. В меню выбрать:
   `Tools → Visual C++ → Component Assignment Tool`.
2. В открывшемся окне выбрать класс.
3. Перетащить класс на значок **VC++**.
4. Подтвердить создание VC++-компонента и его связь с классом.
5. Выбрать существующий проект Visual C++ или создать новый.

**Результат:**
Класс ассоциируется с компонентом VC++ и становится доступным для генерации и обновления кода.

---

### 2. Model Assistant (компонент Model Assistant)

**Назначение:**
Model Assistant используется для интерактивного создания и редактирования структуры класса и его свойств перед генерацией программного кода.

**Возможности:**

* Создание атрибутов и операций класса.
* Задание свойств атрибутов и методов.
* Настройка параметров генерации кода.

**Основные поля окна Model Assistant:**

* **Preview** — отображает текущее описание класса.
* **Generate Code** — определяет, будет ли для класса генерироваться исходный код.
* **Class Type** — выбор типа класса (`class`, `struct`, `union`).
* **Documentation** — произвольные комментарии к классу.

**Дополнительные возможности:**

* Интерактивная настройка свойств методов и атрибутов через диалоговые окна.
* Рекомендуется создавать компоненты именно через Model Assistant, так как в этом случае сохраняется вся информация, необходимая для корректной генерации кода.

### 3. Обновление модели по коду (Update Model)

**Назначение:**
Функция Update Model позволяет синхронизировать модель Rational Rose с изменениями, внесёнными в программный код проекта Visual C++.

**Когда используется:**

* Если после изменения модели исходный код класса был доработан вручную.
* Если в проекте Visual C++ были изменены или удалены классы и компоненты.

**Процесс обновления:**

1. Выбирается команда **Update Model**.
2. В появившемся окне отмечаются классы для обновления (все или выбранные).
3. При необходимости классы связываются с проектом Visual C++.
4. Загружается Microsoft Visual Studio и соответствующий проект.
5. Изменения из кода переносятся в модель.

**Результат:**
Модель Rational Rose обновляется в соответствии с текущим состоянием исходного кода.

---

### 4. Обновление кода по модели (Update Code)

**Назначение:**
Функция Update Code предназначена для генерации и обновления программного кода на основе изменений, внесённых в модель Rational Rose.

**Когда используется:**

* При добавлении новых классов в модель.
* При изменении атрибутов, методов или структуры классов.
* Если в проекте Visual C++ отсутствуют классы, уже описанные в модели.

**Процесс обновления:**

1. Выбирается команда **Update Code**.
2. Указываются классы, для которых необходимо обновить код.
3. Rational Rose вносит изменения в проект Visual C++ на основе модели.
4. По завершении выводится отчёт об обновлении.

**Результат:**
Исходный код полностью соответствует текущей модели.
