## Назначение и возможности Web Modeler

**Web Modeler** — это модуль для Rational Rose, который помогает **моделировать веб-приложения** и **автоматически генерировать код** для них (JSP, ASP, HTML).

### Главные возможности:

1. Создание **модели веб-приложения** на основе существующего кода.
2. Генерация веб-страниц по изменениям в модели.
3. Разработчик сосредоточен на **бизнес-логике и связях**, а Web Modeler берёт на себя детали реализации.

**Пример:**

* Разработчик создаёт модель интернет-магазина: есть страницы “Каталог” и “Корзина”, формы для поиска и оформления заказа.
* Web Modeler генерирует HTML/ASP/JSP код этих страниц, чтобы программист мог сразу запускать приложение.

---

## Особенности использования

1. **Веб-нотация**

   * Чтобы использовать Web Modeler, нужно **преобразовать диаграмму классов в веб-нотацию**.
   * Новых диаграмм не появляется — просто классическая диаграмма получает дополнительные свойства.

2. **Основные инструменты веб-нотации**:

   * **Клиентская страница** – отображается у пользователя (HTML/JSP/ASP).
     *Пример:* страница с каталогом товаров.
   * **Серверная страница** – обрабатывает данные на сервере.
     *Пример:* страница, которая принимает форму “Оформить заказ” и сохраняет данные в базе.
   * **Форма** – элементы ввода данных (input, select, textarea).
     *Пример:* форма для ввода адреса доставки.

3. **Новые типы связей**:

   * **Link** – показывает, что форма принадлежит странице.
     *Пример:* форма “Поиск товаров” связана с клиентской страницей “Каталог”.
   * **Submit** – форма отправляет данные на серверную страницу.
     *Пример:* кнопка “Отправить заказ” передаёт данные на серверную страницу “Обработка заказа”.
   * **Build** – сервер создаёт страницу.
     *Пример:* сервер генерирует страницу “Результаты поиска” после обработки запроса.
   * **Redirect** – одна серверная страница передаёт управление другой (ASP).
     *Пример:* после успешной оплаты страница “Оплата” перенаправляет на “Спасибо за заказ”.
   * **Includes** – одна страница включается в другую.
     *Пример:* верхнее меню сайта вставляется на все страницы.
   * **Forward** – как Redirect, но для JSP.
     *Пример:* JSP страница “Login” передаёт управление на JSP страницу “Dashboard” после успешного входа.

4. **Недостаток:** Web Modeler позволяет строить **только статические страницы**, динамические веб-приложения полностью не моделирует.
