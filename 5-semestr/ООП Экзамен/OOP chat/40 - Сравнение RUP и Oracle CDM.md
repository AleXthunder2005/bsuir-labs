## 40. Сравнительный анализ технологий создания ПС: Rational Unified Process и Oracle

### **1. Rational Unified Process (RUP)**

**Особенности RUP:**

* Разработка ведётся **итерационно и инкрементно**, циклами.
* В каждом цикле четыре стадии:

  1. **Начальная** — определяются цели и бизнес-требования.
  2. **Разработка** — уточнение требований и проектирование архитектуры.
  3. **Конструирование** — реализация и тестирование системы.
  4. **Ввод в действие** — внедрение и передача пользователям.
* **Статические аспекты:** описывают элементы проекта:

  * **Роли** — кто что делает (аналитик, разработчик, тестировщик).
  * **Виды деятельности** — конкретные действия, выполняемые ролями.
  * **Дисциплины** — последовательность действий (реализация, тестирование и др.).
  * **Артефакты** — рабочие продукты проекта (модель, документ, код).
* **Динамические аспекты:** описывают временные и организационные параметры:

  * **Цикл** — создание нового поколения продукта.
  * **Фазы** — крупные стадии разработки (начальная, разработка, конструирование, ввод в действие).
  * **Итерации** — краткосрочные мини-проекты с завершёнными функциями.

### **2. Технология Oracle (CDM)**

В Oracle разработка ведётся с использованием **CDM (Custom Development Method)**.

* **Особенности:**

  * CDM описывает **процессы**, аналогичные статическим аспектам RUP.
  * CDM включает **11 процессов**, выполняемых на **6 этапах (аналог динамических аспектов RUP)**.

#### **11 процессов CDM**

| №  | **Процесс CDM**                          | **Простыми словами**             | **Пример**                   |
| -- | ---------------------------------------- | -------------------------------- | ---------------------------- |
| 1  | **Определение бизнес-требований**        | Что нужно бизнесу и зачем        | Нужна система учёта клиентов |
| 2  | **Изучение существующих систем**         | Что уже есть сейчас              | Анализ старой БД или Excel   |
| 3  | **Определение технической архитектуры**  | Как система будет устроена       | Выбор Oracle DB, Forms       |
| 4  | **Проектирование базы данных**           | Планирование структуры БД        | Схема таблиц и связей        |
| 5  | **Разработка базы данных**               | Создание БД                      | Таблицы, индексы             |
| 6  | **Проектирование программных модулей**   | Проектирование логики            | Схемы форм и отчётов         |
| 7  | **Разработка программных модулей**       | Написание кода                   | Формы, отчёты, процедуры     |
| 8  | **Конвертация данных**                   | Перенос данных из старой системы | Импорт данных                |
| 9  | **Документирование**                     | Подготовка документации          | Руководство пользователя     |
| 10 | **Тестирование и обучение**              | Проверка системы и обучение      | Тесты, обучение персонала    |
| 11 | **Внедрение, поддержка и сопровождение** | Запуск и дальнейшая работа       | Эксплуатация системы         |

#### **Этапы CDM (аналог динамических аспектов RUP)**

| **Этап**           | **Назначение**                    |
| ------------------ | --------------------------------- |
| **Стратегия**      | Определение целей и требований    |
| **Анализ**         | Детализация требований            |
| **Проектирование** | Архитектура, БД, модули           |
| **Реализация**     | Создание и тестирование           |
| **Внедрение**      | Ввод в эксплуатацию               |
| **Эксплуатация**   | Поддержка и сопровождение системы |

### **3. Сравнение RUP и Oracle (CDM)**

| **Признак**              | **RUP**                                                  | **Oracle (CDM)**                                           |
| ------------------------ | -------------------------------------------------------- | ---------------------------------------------------------- |
| Основной принцип         | Итерационный и инкрементный подход                       | Процессный подход CDM с фазами                             |
| Статические элементы     | Роли, виды деятельности, дисциплины, артефакты           | 11 процессов CDM                                           |
| Динамические элементы    | Циклы, фазы, итерации                                    | 6 этапов CDM                                               |
| Основной результат       | Гибкая система с рабочими версиями после каждой итерации | Полная система с документацией, тестированием и внедрением |
| Используемые инструменты | RUP поддерживается UML-моделированием                    | Oracle Designer, Oracle Forms, Oracle DB                   |
