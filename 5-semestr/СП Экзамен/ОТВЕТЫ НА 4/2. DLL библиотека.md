## 2. Понятие динамически-загружаемой библиотеки. Создание DLL-библиотеки. Использование DLL-библиотеки в программе методом загрузки на старте и методом загрузки во время работы программы. 

# **Динамически-загружаемые библиотеки (DLL) в Windows**

---

## 1️⃣ Что такое DLL

**DLL (Dynamic Link Library)** — это файл с кодом, данными и ресурсами, который может **использоваться разными программами**.

* Содержит **много точек входа** (функции, переменные, классы), которые можно вызывать из других программ.
* Программы подключают DLL и используют её функции, не включая весь код в свой EXE.
* Пример: `user32.dll` для окон и кнопок, `kernel32.dll` для работы с файлами и памятью.

---

## 2️⃣ Экспорт и импорт функций DLL

**Экспорт** — когда DLL говорит: «Вот функции, которые можно использовать».
**Импорт** — когда программа говорит: «Я хочу использовать эти функции из DLL».

### Пример: экспорт функции

```cpp
// В DLL
__declspec(dllexport) int Min(int x, int y);
```

* `__declspec(dllexport)` — функция доступна другим программам.

### Пример: импорт функции

```cpp
// В EXE
__declspec(dllimport) int Min(int x, int y);
```

* EXE использует функцию, но код функции находится в DLL.

---

## 3️⃣ Статический и динамический импорт

### 🔹 Статический импорт

* DLL подключается **при старте программы**.
* Visual Studio создаёт **LIB-файл** — маленький «трамплин», через который EXE вызывает DLL.
* Пример использования:

```cpp
#include "MyDLL.h"
int result = Min(3, 5); // вызов функции из DLL
```

* Код DLL **загружается автоматически** при запуске EXE.

---

### 🔹 Динамический импорт

* DLL загружается **во время работы программы**, когда она реально нужна.
* Пример:

```cpp
#include <windows.h>

typedef int (*MinFunc)(int, int);

HMODULE hDLL = LoadLibrary("MyDLL.dll"); // загружаем DLL
MinFunc Min = (MinFunc)GetProcAddress(hDLL, "Min"); // получаем адрес функции
int result = Min(3, 5); // вызываем функцию
FreeLibrary(hDLL); // выгружаем DLL
```

* Полезно, если DLL нужна не всегда или может отсутствовать.

---

## 4️⃣ Соглашения о вызовах функций

Когда функция вызывается из DLL, нужно договориться **как передавать параметры** и кто освобождает стек.

| Соглашение   | Что делает                                                                                |
| ------------ | ----------------------------------------------------------------------------------------- |
| `__cdecl`    | Параметры на стек в обратном порядке, стек освобождает вызывающая программа               |
| `__stdcall`  | Параметры на стек в обратном порядке, стек освобождает функция (стандарт для Windows DLL) |
| `__pascal`   | Параметры на стек в прямом порядке, освобождает функция                                   |
| `__register` | Передача через регистры (редко, нестандартно)                                             |

💡 В Windows **стандартная DLL использует `__stdcall`**, поэтому имена функций меняются на `_Имя@N` (где N — размер параметров в байтах).

---

## 5️⃣ Функция входа/выхода DLL (`DllMain`)

* Каждая DLL может иметь **одну функцию инициализации/завершения**:

```cpp
BOOL WINAPI DllMain(HINSTANCE hinstDLL, DWORD fdwReason, LPVOID lpvReserved) {
    switch(fdwReason) {
        case DLL_PROCESS_ATTACH:  // DLL загружается в процесс
            break;
        case DLL_PROCESS_DETACH:  // DLL выгружается
            break;
    }
    return TRUE;
}
```

* Используется для **инициализации ресурсов** или очистки памяти.
* Если DLL **только с функциями**, её можно не реализовывать.

---

## 6️⃣ Минимальный пример DLL

**DLL с одной функцией:**

```cpp
// MyDLL.h
__declspec(dllexport) int Min(int x, int y);

// MyDLL.cpp
#include "MyDLL.h"

int Min(int x, int y) {
    return (x < y) ? x : y;
}
```

**EXE, использующий DLL (статически):**

```cpp
#include "MyDLL.h"
#include <iostream>

int main() {
    int m = Min(10, 5);
    std::cout << m; // 5
}
```

**EXE, использующий DLL динамически:**

```cpp
#include <windows.h>
#include <iostream>

typedef int (*MinFunc)(int, int);

int main() {
    HMODULE hDLL = LoadLibrary("MyDLL.dll");
    MinFunc Min = (MinFunc)GetProcAddress(hDLL, "Min");
    int m = Min(10, 5);
    std::cout << m; // 5
    FreeLibrary(hDLL);
}
```

---

### 🔑 Главное для экзамена

* DLL — **библиотека функций, которую можно использовать в нескольких программах**
* **Экспорт** — функции, доступные другим; **Импорт** — использование этих функций
* **Статический импорт** — DLL загружается при старте
* **Динамический импорт** — DLL загружается во время работы программы
* **Соглашение вызова `__stdcall`** — стандарт для Windows
* `DllMain` — функция инициализации DLL, не обязательна для библиотек с ресурсами

## 2️⃣ Что внутри DLL

DLL — это **исполняемый модуль Windows** (`.dll`):

* **Код функций** — машинные инструкции (CPU).
* **Данные** — глобальные переменные, константы, ресурсы.
* **Таблица экспорта** — список функций и переменных, которые можно вызывать из других программ.
* **Таблица импорта** — если DLL использует функции других DLL.
* **Ресурсы** — иконки, меню, строки, диалоги.

Простая аналогия:

> DLL = «книга с функциями и ресурсами»,
> `.lib` = «оглавление книги», показывающее, где искать функции».

---

## 3️⃣ Как EXE и DLL работают вместе

* При **статическом импорте**:

  1. EXE использует `.lib` при компиляции
  2. Код функции вызывается из DLL автоматически при запуске программы

* При **динамическом импорте**:

  1. EXE **загружает DLL сам** (`LoadLibrary`)
  2. Получает адрес функции (`GetProcAddress`)
  3. Вызывает её напрямую

---

## **Алгоритм вызова функции из DLL в EXE (статический импорт)**

1. **Компиляция EXE с DLL:**

   * EXE содержит «трамплин» (stub) для функции.
   * В EXE есть Import Table с информацией о DLL и функциях.
   * Создаётся Import Address Table (IAT) с пустыми адресами.

2. **Запуск EXE:**

   * Windows Loader видит Import Table EXE.
   * Loader ищет DLL на диске и загружает её в память.

3. **Связывание функций:**

   * Loader берёт Export Table DLL и находит реальные адреса функций.
   * Адреса функций записываются в IAT EXE.

4. **Вызов функции из EXE:**

   * EXE вызывает stub (трамплин).
   * Stub делает прыжок через IAT на адрес функции в DLL.
   * Код функции в DLL выполняется.

5. **Результат:**

   * Результат работы функции возвращается EXE.
   * Если вызов повторяется, прыжок через IAT идёт сразу, DLL уже в памяти.
