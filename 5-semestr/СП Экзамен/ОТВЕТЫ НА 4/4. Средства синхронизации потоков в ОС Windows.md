# **Средства синхронизации потоков в Windows**

Синхронизация нужна, чтобы **несколько потоков не портили данные друг друга** и работали корректно при параллельном выполнении.

---

## **1️⃣ Между потоками одного процесса**

### **Критическая секция (Critical Section)**

* Используется для защиты **небольших участков кода**.
* Только **один поток одновременно** может выполнять этот код.
* Быстро работает, но **только внутри одного процесса**.

**Пример:**

```cpp
CRITICAL_SECTION cs;
InitializeCriticalSection(&cs);

EnterCriticalSection(&cs);
// Здесь работа с общими данными
LeaveCriticalSection(&cs);

DeleteCriticalSection(&cs);
```

---

### **Условная переменная (Condition Variable)**

* Поток может ждать, пока **не выполнится какое-то условие**.
* Работает вместе с критической секцией.
* Потоки «засыпают», пока условие не выполнится, и «просыпаются» с помощью Wake функции.

**Пример:**

```cpp
CONDITION_VARIABLE cv;
InitializeConditionVariable(&cv);

SleepConditionVariableCS(&cv, &cs, INFINITE); // ждем события
WakeConditionVariable(&cv);                   // разбудить один поток
WakeAllConditionVariable(&cv);                // разбудить всех потоков
```

---

### **Атомарные операции (Interlocked Functions)**

* Операции над переменной выполняются **целиком или не выполняются**.
* Не нужны критические секции, очень быстро, без переключения в режим ядра.

**Пример:**

```cpp
LONG counter = 0;
InterlockedIncrement(&counter); // увеличить на 1 безопасно
InterlockedDecrement(&counter); // уменьшить на 1 безопасно
```

---

### **Барьер (Synchronization Barrier)**

* Ждём, пока **определённое число потоков** достигнет точки синхронизации.
* После этого все потоки продолжают работу.
* Используется для коллективных вычислений.

```cpp
SYNCHRONIZATION_BARRIER barrier;
InitializeSynchronizationBarrier(&barrier, 4, -1); 
// 4 — сколько потоков должно дойти до барьера
// -1 — система сама выбирает, как ждать (оптимально)

EnterSynchronizationBarrier(&barrier, 0);
// поток дошёл до точки синхронизации и ждёт остальные 3
// когда все 4 потока здесь — все продолжают выполнение

DeleteSynchronizationBarrier(&barrier);
```

## **2️⃣ Между потоками разных процессов**

### **Мьютекс (Mutex)**

* Объект ядра, позволяет **одному потоку в любом процессе** владеть ресурсом.
* Может быть **именованным** (делиться между процессами) или безымянным (только внутри одного процесса).

**Пример:**

```cpp
HANDLE hMutex = CreateMutex(NULL, FALSE, "MyMutex");

WaitForSingleObject(hMutex, INFINITE); // захватить ресурс
// Работа с ресурсом
ReleaseMutex(hMutex);
CloseHandle(hMutex);
```

---

### **Семафор (Semaphore)**

* Счётчик ресурсов.
* Можно разрешить доступ сразу **нескольким потокам**, до заданного числа.
* Используется для контроля количества ресурсов.

**Пример:**

```cpp
HANDLE hSem = CreateSemaphore(NULL, 0, 5, NULL); // максимум 5 ресурсов
WaitForSingleObject(hSem, INFINITE);            // захватить ресурс
// Работа с ресурсом
ReleaseSemaphore(hSem, 1, NULL);                // освободить один ресурс
```

---

### **Событие (Event)**

* Поток ждёт, пока объект события **становится сигнализированным**.
* Может быть с **автосбросом** (будет проснуться только один поток) или **ручным сбросом** (все потоки).

**Пример:**

```cpp
HANDLE hEvent = CreateEvent(NULL, TRUE, FALSE, NULL); // TRUE = ручной сброс
WaitForSingleObject(hEvent, INFINITE);               // ждать события
SetEvent(hEvent);                                    // сигнализировать событие
ResetEvent(hEvent);                                  // сброс события
```

---

### **Ожидаемый таймер (Waitable Timer)**

* Поток может ждать до определённого времени или интервала.
* После срабатывания таймера, поток продолжается автоматически.

**Пример:**

```cpp
HANDLE hTimer = CreateWaitableTimer(NULL, FALSE, NULL); // FALSE = автосброс
LARGE_INTEGER liDueTime;
liDueTime.QuadPart = -10000000LL; // 1 секунда
SetWaitableTimer(hTimer, &liDueTime, 0, NULL, NULL, FALSE);
WaitForSingleObject(hTimer, INFINITE); // ждать таймер
CloseHandle(hTimer);
```

---

## **3️⃣ Между потоками удалённых процессов**

* **Mailslot** – почтовый ящик для сообщений.
* **Pipe (Named/Unnamed)** – канал передачи данных между процессами.
* **Windows Socket** – сетевое соединение.

## 🔔 **Событие (Event) — как с ним работают**

### Что это по смыслу

**Event = флаг**
*пока флаг = 0 → потоки спят*
*поставили флаг = 1 → потоки проснулись*

---

### Типичный алгоритм работы с Event

```cpp
HANDLE hEvent = CreateEvent(
    NULL,
    TRUE,   // ручной сброс (FALSE — автосброс)
    FALSE,  // начальное состояние: несигнализировано
    NULL
);
```

#### 1️⃣ Поток-потребитель (ждёт ресурс)

```cpp
WaitForSingleObject(hEvent, INFINITE);
// здесь ресурс готов, можно с ним работать
```

#### 2️⃣ Поток-производитель (сообщает)

```cpp
// ресурс подготовлен
SetEvent(hEvent);   // сообщаем всем (или одному — если автосброс)
```

#### 3️⃣ Сброс (только для ручного сброса)

```cpp
ResetEvent(hEvent); // снова перевели в режим ожидания
```

---

### 📌 Когда что использовать

| Тип                     | Зачем                    |
| ----------------------- | ------------------------ |
| **Автосброс (FALSE)**   | разбудить **один поток** |
| **Ручной сброс (TRUE)** | разбудить **все потоки** |

---

### 🔧 Пример из жизни

* загрузка данных завершена → `SetEvent`
* несколько потоков ждут → все стартуют одновременно
