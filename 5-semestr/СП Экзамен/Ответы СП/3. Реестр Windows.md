# **Системный реестр операционной системы Windows**

---

## Что такое системный реестр Windows

**Системный реестр** — это центральная база данных Windows, в которой хранятся:

* настройки операционной системы,
* параметры оборудования,
* сведения о пользователях,
* настройки программ.

Проще говоря, реестр — это **«настройки Windows и программ в одном месте»**.

---

## Структура и главные разделы реестра

Реестр имеет **иерархическую структуру**, похожую на папки и файлы.

### 1️⃣ Ветви (HKEY_*) — самый верхний уровень

В Windows есть **пять основных ветвей**:

* **HKEY_CLASSES_ROOT** — информация о типах файлов и программах, которые их открывают.
* **HKEY_CURRENT_USER** — настройки **текущего пользователя**.
* **HKEY_LOCAL_MACHINE** — настройки **всего компьютера** (оборудование, драйверы, ПО).
* **HKEY_USERS** — профили всех пользователей системы.
* **HKEY_CURRENT_CONFIG** — текущая конфигурация оборудования.

---

### 2️⃣ Ключи (Keys)

* Похожи на **папки** внутри ветвей.
* Бывают:

  * **системные** — изменять опасно (может нарушить работу Windows);
  * **пользовательские** — создаются программами или администратором.

---

### 3️⃣ Подключи (Subkeys)

* Это ключи внутри других ключей.
* Не имеют строгих ограничений по названиям.
* Могут быть системными или пользовательскими.

---

### 4️⃣ Параметры (Values)

* **Хранят сами данные**.
* Представляют собой пару **«имя — значение»**.
* Именно параметры определяют, **как работает Windows и программы**.

---

## Точки автозапуска программ

**Автозапуск** — это способы, с помощью которых программы запускаются автоматически при старте системы или входе пользователя.

Основные точки автозапуска:

* **Папка «Автозагрузка»** — всё, что там лежит, запускается при входе в систему.
* **Реестр Windows**:

  * отдельно для текущего пользователя и для всех;
  * запуск один раз или при каждом старте.
* **Планировщик заданий** — запуск программ по расписанию или при событиях.
* **Службы Windows** — фоновые программы, запускаемые вместе с системой.
* **Групповые политики** — централизованное управление автозапуском.

---

## Средства редактирования реестра Windows

Для работы с реестром используются:

* **Regedit.exe / Regedt32.exe** — стандартные редакторы реестра.
* **Групповые и системные политики**.
* **REG-файлы** — текстовые файлы для импорта настроек.
* **Сценарии и программы** (например, на Visual Basic).

⚠️ Неправильное редактирование реестра может привести к сбоям системы.

---

## Работа с реестром из приложения

Программы могут работать с реестром через специальные функции Windows API.

### Основные группы функций:

### 🔹 Открытие и закрытие ключей

* `RegOpenKeyEx` — открывает существующий ключ.

---

### 🔹 Чтение данных

* `RegQueryValueEx` — читает значение параметра.
* `RegGetValue` — читает значение, включая вложенные ключи.

---

### 🔹 Запись данных

* `RegSetValueEx` — записывает значение параметра.
* `RegCreateKeyEx` — создаёт или открывает ключ.

---

### 🔹 Удаление данных

* `RegDeleteValue` — удаляет параметр.
* `RegDeleteKey` — удаляет ключ.
* `RegDeleteTree` — удаляет ключ со всеми вложенными.

---

### 🔹 Перечисление

* `RegEnumKeyEx` — список подключей.
* `RegEnumValue` — список параметров.

---

### 🔹 Дополнительные функции

* `RegQueryInfoKey` — информация о ключе.
* `RegSaveKey` / `RegRestoreKey` — сохранение и восстановление реестра из файла.

---

### Коротко для экзамена:

* Реестр — база настроек Windows и программ
* Структура: ветви → ключи → подключи → параметры
* Автозапуск возможен через папку, реестр, службы и планировщик
* Редактирование — через Regedit или программы
* Доступ из приложений — через функции Windows API
